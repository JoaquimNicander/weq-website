# WEQ.SE

Webbsida för WEQ – personaliserad video i skala.

## Struktur
- `index.html` – huvudsida
- `css/style.css` – stilmall
- `js/main.js` – animationer och kontaktformulär
- `assets/` – logotyp och bilder

## Hosting
Publiceras via GitHub Pages på [weq.se](https://weq.se).

## Deploy
```bash
git add .
git commit -m "Update"
git push origin main
```
GitHub Pages publicerar automatiskt från `main`-branchen.
